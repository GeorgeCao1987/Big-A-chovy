隐私政策

最后更新：2026-09-22

本政策适用于“阿狼股票数据服务”（以下简称“本服务”）。本服务提供只读的 A 股市场数据、板块扫描、候选发现和个股数据接口。

1. 我们处理的信息

本服务不要求用户注册账户，也不主动收集支付信息、身份证件信息或交易账户凭据。本服务不会读取或保存你的 ChatGPT 对话内容。

为保障运行与排错，托管平台和 Web 服务器可能自动产生基础技术日志，例如请求时间、请求路径、IP 地址、User-Agent、响应状态码和错误信息。这些信息仅用于安全、稳定性、故障诊断和容量分析。

2. 市场数据来源

本服务会从第三方行情与公开信息接口获取证券市场相关数据。第三方服务可能拥有各自的隐私政策和服务条款，本服务无法控制其可用性、数据完整性或政策变化。

3. 信息使用方式

技术日志仅用于维护服务、排查故障、防止滥用和改进稳定性。我们不会出售用户个人数据，也不会将技术日志用于广告画像。

4. 数据保留与安全

日志保留周期取决于当前托管平台和基础设施配置。我们会尽量减少不必要的数据收集，并使用托管平台提供的基础安全能力保护服务。

5. 联系与问题反馈

如对隐私政策或数据处理方式有疑问，请通过 GitHub Issues 联系：
