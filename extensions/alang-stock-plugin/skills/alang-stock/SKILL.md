# 阿狼 × Big-A-chovy 选股

本 Skill 的核心不是预测涨跌，而是把 Big-A-chovy 当作“全市场雷达”，把阿狼体系当作“最终分析和条件策略层”。

## 来源与归属

回答时必须区分：

- **【阿狼原始体系】**：来自项目中的《【狼大】自立自强》及后续阿狼原始发言支持的规则。
- **【Big-A-chovy筛选】**：来自仓库现有筛选器、`screeners.md`、`rule_config.py`、风险标签和状态机的候选发现结果。
- **【融合推导】**：将两套方法组合后的工作流，不冒充阿狼原话，也不冒充 Big-A-chovy 原规则。
- **【实时数据补充】**：由 MCP 工具或其他当日可靠数据得到的行情、资金、公告、基本面和事件数据。

详细融合边界见 `references/fusion-rules.md`。

## 默认范围

默认只研究 A 股主板 `00/60`，排除创业板、科创板、北交所、ST/*ST、退市风险和停牌股。用户明确要求其他市场时再扩展。

## 实时要求

用户问“今天、现在、盘中、明天”或具体股票当前状态时，必须先取最新数据并标明时间。

严禁拿旧报告当当前行情。工具缺字段时直接写“尚未确认/数据不足”，不得自己补值。

## 标准执行顺序

### 1. 先判断大盘，不先看股票

先调用 `market_snapshot`。至少检查：

- 上证、沪深300、科创50；必要时参考深证成指。
- 日K及 5/10/13/20/60/144 日均线。
- 当前指数所处支撑、压力、缺口附近的位置。
- 能获得的成交额、上涨/下跌家数和数据质量。

若需要完整全市场宽度，调用 `scan_candidates` 并读取其 `breadth`，不要把快速指数接口的成分统计冒充全市场宽度。

【阿狼原始体系】仓位服从市场环境。明确下跌趋势、风险阶段和大级别压力附近，先降低进攻欲望；没有趋势扭转，不因“跌很多”主观抄底。

### 2. 再找市场认可的方向

调用 `sector_rank`，优先看“涨幅、成交额、资金、上涨家数”是否同时靠前，再用候选股数量和个股量价验证。

`recognition_score` 只是【融合推导】的辅助排序分，不是阿狼原话，也不是买入许可。

板块判断遵循：

- 市场已经用资金和成交确认的方向优先于故事。
- 多只同方向个股出现相似量价结构，比单股脉冲更可信。
- 有核心、容量、二线和轮动梯队的方向优于所有股票一起高潮后衰退的方向。
- 消息密集、事件密集可加分，但盘中突发消息脉冲不能单独作为追涨理由。

### 3. Big-A-chovy 扫全市场候选

调用：

`scan_candidates(mode="all", top=15, check_announcements=true)`

Big-A-chovy 的标签只解释为候选发现层：

- `strict_ultra`：短线动能原始候选。
- `trend_observation / strict_trend`：趋势观察/确认候选。
- `low_ultra / low_trend`：低吸或趋势低吸候选。
- `dual_pool / pre_intersection / intersection_states`：多条件同时出现的优先研究信号。
- `watchlist`：触发和观察数据。
- 主力、超大单、5分钟/15分钟增量、VWAP、板块共振：作为资金与量价证据。

**禁止把 A/B/C、dual_pool、ENTRY_ELIGIBLE 等筛选标签直接改写成“可以买”。**

### 4. 用阿狼体系二次淘汰

从最强方向中的候选开始，不按涨幅机械取前几名。

强势板块优先研究：

- 核心趋势股。
- 容量核心。
- 尚未连续加速的二线补涨。
- 上涨补量、回调缩量、靠近有效支撑而不是远离支撑的股票。

弱势板块只保留明显强于板块、结构独立的强势股，普通跟随股不做。

明显排除：

- 情绪高潮后的追高。
- 纯消息瞬时脉冲。
- 连续异常加速。
- 公告 `avoid`、ST、退市/重大财务风险。
- 下跌趋势尚未结束。
- 个股量价与板块资金行为明显矛盾。

公告 `unknown` 表示未完成核验，不得自动当作 clean。

### 5. 必须判断趋势演化阶段

【阿狼原始体系】完整链条：

`下跌 → 缩量 → 止跌 → 企稳 → 反抽 → 压力位补量 → 反弹 → 过颈线 → 加强 → 新高 → 反转`

不得跳阶段。

关键解释：

- 下跌很多 ≠ 买点。
- 缩量只是形成反抽的条件之一。
- 反抽到压力位后有成交量支持，才可能升级为反弹。
- 突破关键压力后还要观察是否继续加强。
- 缩量跌破和放量跌破不能等同处理；关键位必须结合量能。

### 6. 所有技术判断都必须带量

至少回答：

- 上涨有没有补量？
- 回调有没有缩量？
- 压力位突破有没有补量？
- 下跌是主动放量撤退，还是缩量抛压衰减？
- 个股与板块是否量价共振？
- 如果缺少昨日同期量能，明确写缺失，不能用当日绝对成交量冒充同期比较。

需要深入候选时，对少数股票调用 `stock_detail`，查看实时价、五档、分时、15分钟聚合、均线和公告。

### 7. 基本面、消息面与资金面不能被技术图替代

阿狼体系不是纯技术分析。对最终少数候选，按可获得数据补查：

- 为什么涨跌、政策影响哪个方向。
- 监管与 GJD 迹象。
- 行业景气、业绩、CAPEX、海外产业链。
- 投资日历、会议和经济数据。

如果这些数据尚未由插件提供，可用可靠外部实时资料补充，并标为【实时数据补充】。

基本面、资金面、技术面明显矛盾时，必须把矛盾列出来，不强行给单一结论。

## 融合裁决原则

发生冲突时按以下方式处理：

1. Big-A-chovy 负责“发现谁值得看”，不是最终交易裁决。
2. 阿狼的大盘和板块前置条件可以否决一个机器分数很高的个股。
3. Big-A-chovy 的 VWAP、资金增量、公告、换手、量比、均线等字段用于补证据，不替代趋势演化链。
4. 机器筛选未入榜不等于绝对不能研究；但若无明确理由，不绕过全市场雷达主观硬找票。
5. 任何加仓必须来自新的确定性条件，不能因为亏损补仓。

## 方向选股输出

用户问“今天做什么、哪些方向有机会、怎么选股”时，按以下顺序输出：

**结论**：市场阶段 + 当前仓位倾向（进攻/保持/防守）。

**1. 大盘**：指数结构、量能、关键压力支撑、当前阶段。

**2. 最强方向**：只保留资金、成交和个股共振较好的少数方向；说明为什么市场认可。

**3. 暂时不能做的方向**：说明是退潮、无量、过热、纯消息还是趋势未扭转。

**4. 主板候选**：只保留少数真正值得继续研究的股票，不凑数量。每只说明来自哪个 Big-A 池、板块地位、趋势阶段、量价和风险。

**5. 条件策略**：必须写成条件句，例如：

- 当 `板块继续加强 + 个股回踩缩量不破关键位 + 再次向上补量` → 才考虑执行。
- 当 `压力位突破但明显缩量` → 不追。
- 当 `板块转弱或个股放量跌破结构` → 原判断失效。

## 个股输出

分析具体股票默认使用：

**结论**：可做 / 观察 / 不做 / 持有 / 减仓，并写当前趋势阶段。

**1. 大盘**：当前环境允许多大风险。

**2. 板块**：是不是当前资金方向、相对强弱和梯队位置。

**3. 个股**：趋势、量价、资金、位置、相对板块强弱。

**4. 关键位置**：尽量给具体价格；无法从数据确认时不猜。

**5. 条件策略**：A+B+C 时做什么；D 时不做；E 时原判断失效。

**6. 仓位**：说明当前适合进攻、保持还是防守；不因亏损机械补仓。

## 做T补充

用户明确问做T时，仍然先看市场和板块，再看个股15分钟和量能。做T只是辅助，不得破坏原始买入逻辑。

优先观察：上涨放量、回调缩量、接近支撑由缩量转放量；主升结构中不要为了频繁反T丢失核心仓位。若分时/15分钟数据不足，明确说不能精确判断日内高低点。

## 禁止

- 不预测“明天一定涨/跌”。
- 不因为便宜、跌得多、估值低、故事好就给买点。
- 不只看K线或均线，不看量能。
- 不把模型自己的融合规则伪装成阿狼原话。
- 不自动下单。
