# 阿狼 × Big-A-chovy 融合规则

本文件只服务于 `alang-stock` Skill，不修改仓库根目录原有 `盘中` Skill 和《选股框架.md》。目的：保留 Big-A-chovy 的全市场发现能力，同时把最终分析顺序切换为阿狼体系的大盘→板块→个股→条件策略。

## 1. 两套方法各自负责什么

### 阿狼原始体系负责

- 先判断市场环境，再决定仓位容忍度。
- 先选方向，再选股票。
- 用完整趋势演化链判断当前阶段：`下跌 → 缩量 → 止跌 → 企稳 → 反抽 → 压力位补量 → 反弹 → 过颈线 → 加强 → 新高 → 反转`。
- 所有技术判断必须结合量能；上涨、回调、突破、跌破都不能脱离量。
- 市场认可优先于题材故事；多只同方向个股出现类似量价结构是重要确认。
- 强势板块找核心、容量和未加速的二线补涨；弱势板块只看明显强于板块的股票。
- 基本面、资金面、消息面和技术面发生矛盾时，明确列出矛盾。
- 用“出现什么条件→做什么；没有出现→不做；什么条件失效→修改策略”的方式操作。

来源依据：项目《【狼大】自立自强》中的趋势链、量价、反抽/反弹、板块方向、市场认可、调整期、15分钟与做T相关原始发言。

## 2. Big-A-chovy 原始筛选负责

Big-A-chovy 当前发现层已经提供：

- 主板范围、ST/退市/停牌等基础排除。
- `strict_ultra`：严格超短动能候选。
- `trend_observation / strict_trend`：趋势观察与趋势确认。
- `low_ultra / low_trend`：低吸与趋势低吸候选。
- `watchlist`：触发价、支撑区和观察状态。
- `dual_pool / pre_intersection / intersection_states`：多池同时满足后的状态跟踪。
- VWAP、换手、量比、成交额、均线、日内高点回落。
- 主力、超大单、大单、5分钟/15分钟资金增量。
- 行业/板块共振与公告风险。

这些字段的数值阈值继续由仓库现有 `tools/rule_config.py` 和筛选引擎维护，Skill 不复制一套固定参数，避免将来和上游漂移。

## 3. 标签映射

| Big-A 输出 | 在融合体系中的解释 | 不能直接解释成 |
|---|---|---|
| strict_ultra | 短线动能值得看 | 买入 |
| strict_trend | 趋势条件较完整的机器候选 | 趋势已反转 |
| low_ultra A/B/C | 当前低吸结构质量标签 | 阿狼买点 |
| low_trend | 趋势低吸机器候选 | 确定性买点 |
| dual_pool | 多筛选条件重叠，优先研究 | 必涨/可买 |
| pre_intersection | 接近交集状态 | 提前埋伏许可 |
| ENTRY_ELIGIBLE | Big-A 状态机内部可进入下一决策层 | 阿狼最终开仓许可 |
| resonance | Big-A 对板块共振的量化证据 | 主线已经确认 |
| clean/watch/avoid/unknown | 公告风险字段 | 对完整基本面的替代 |

## 4. 融合后的实际漏斗

### 第一道：市场门

若指数仍处于明确下跌、关键支撑放量失守、风险阶段或大级别压力附近，降低候选权重和仓位容忍度。

机器筛选再漂亮，也不能跳过市场门。

### 第二道：板块门

一个方向优先保留需要同时看到多个证据：

- 板块涨幅有相对优势。
- 成交额活跃或继续放大。
- 主力资金不弱。
- 上涨家数有扩散。
- Big-A 候选不是只有一只孤立脉冲股。

`sector_rank.recognition_score` 是上述四类可量化字段的辅助合成分，只用于减少搜索范围。最终“是不是主线”仍由模型结合市场和候选结构判断。

### 第三道：个股门

优先从强方向中找：

- 核心趋势股。
- 容量核心。
- 尚未连续加速的二线补涨。
- 回调缩量、上攻补量、靠近可验证支撑的位置。

拒绝：连续异常加速、消息瞬时脉冲、下跌趋势未结束、板块弱而个股也不强、公告硬风险。

### 第四道：趋势阶段门

即使进入 Big-A 的严格池，也必须重新放回阿狼趋势链判断。

例如：

- `价格在MA5/10/20上方` 不等于已经“反转”。
- `low_ultra A` 如果仍处于下跌且没有止跌/企稳，只能观察。
- `strict_ultra + dual_pool` 如果到了大压力位却没有补量，也不能追。
- 反抽在压力位补量并有效通过，才有资格讨论升级为反弹。

### 第五道：量价门

至少核验：

- 上涨是否放量。
- 回调是否缩量。
- 压力突破是否补量。
- 下跌放量还是缩量。
- 个股与板块是否共振。
- 主力/超大单/5分钟/15分钟资金变化是否支持价格行为。

量比、VWAP、资金字段都只是量价证据的一部分，不单独决定结论。

## 5. 冲突处理

### Big-A 强，阿狼环境弱

结论：候选保留观察，不因为机器评分高而绕过市场/板块风险。

### 阿狼方向强，但 Big-A 没有候选

先检查：

- 是否因为涨幅、价格、市值等 Big-A 硬阈值被过滤。
- 数据源是否降级或筛选快照不完整。
- 当前是不是还没到机器条件触发阶段。

若没有这些原因，不主观为了凑股票硬找。

### 资金强，技术结构弱

资金字段不能覆盖趋势结构。观察资金能否把结构修复出来。

### 技术结构强，资金/量能弱

关键压力位缺量时不把图形突破当有效突破。

### 消息逻辑强，市场不认可

不把“作文很好”升级为主线。先等成交、资金、板块扩散确认。

## 6. 调整期处理

阿狼原始体系在调整期强调顺序：先降仓位、找相对抗跌/抢先反弹方向、没有重回趋势不乱加回仓位，最后才是用灵活仓做超额。

因此在调整期：

- Big-A 的 `low_*` 池用于发现可能出现止跌和企稳的股票。
- 不因为进入低吸池就抄底。
- 只有板块和个股都不创新低、量能衰减后出现补量向上，才提高优先级。

## 7. 做T融合

Big-A 提供 VWAP、分时、15分钟、资金和盘口证据；阿狼体系决定是否适合做T。

原则：

- 先市场、板块，再个股。
- 日K判断趋势，15分钟服务日内操作。
- 上涨放量、回调缩量优于相反结构。
- 支撑附近缩量转放量可作为候选进场节点。
- 主升中少做反T，避免卖飞趋势仓。
- 每一次T都是新的买卖，不能让T破坏最初持仓逻辑。

## 8. 数据缺口

首版云端工具故意不伪造以下字段：

- 昨日同期成交额/成交量。
- 完整逐笔主动买卖。
- A50/期指/两融/GJD ETF 实时组合判断。
- 完整公司基本面、CAPEX、海外产业链。

这些缺口必须在回答中明确，必要时通过可靠外部实时数据补充。
